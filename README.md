## 📁 Repository Structure

```text
├── ICC-Dashboard.pbix   # Interactive Power BI Dashboard report & data model
├── icc_dataset.xlsx     # Historical ICC tournament dataset (matches, teams, stats)
├── ICC-Trophies.jpg     # Visual preview / header banner
└── README.md            # Project documentation

```

---

## 🛠️ Tech Stack & Tools

* **Business Intelligence & Reporting:** Power BI Desktop
* **Data Modeling & Analytics:** DAX (Measures, calculated columns, dynamic KPI indicators)
* **Data Transformation:** Power Query (Data cleaning, reshaping, and date handling)
* **Data Source:** Microsoft Excel (`icc_dataset.xlsx`)

---

## 📊 Key Highlights & Visualizations

* **Tournament History & Winners:** Historical breakdown of champions, runners-up, host nations, and win margins across tournament editions.
* **Team Performance Analytics:** Overall win/loss ratios, head-to-head records, and knockout stage conversion rates.
* **Match & Player Insights:** High-impact batting and bowling milestones, top run-scorers, highest wicket-takers, and venue-specific trends.
* **Dynamic Slicers:** Interactive filters by tournament format (ODI / T20 / Champions Trophy), edition year, host country, and participating teams.

## 🚀 Getting Started

1. **Clone the Repository:**
```bash
git clone [https://github.com/moha0808/ICC-Dashboards.git](https://github.com/moha0808/ICC-Dashboards.git)

```


2. **Open the Report:**
* Install and launch [Power BI Desktop](https://powerbi.microsoft.com/).
* Open `ICC-Dashboard.pbix`.


3. **Data Source Setup:**
* If prompted to refresh data, go to **Transform Data > Data Source Settings** and update the file path to point to your local copy of `icc_dataset.xlsx`.
